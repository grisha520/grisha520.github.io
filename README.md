# ФинПлан

Офлайн-приложение для личного финансового плана и учёта портфеля (PWA).

- Данные хранятся только на устройстве пользователя и шифруются его паролем (PBKDF2-SHA256, 600 000 итераций → AES-256-GCM).
- В репозитории только код приложения — никаких пользовательских данных здесь нет.
- Без внешних библиотек, шрифтов и аналитики. Единственный сетевой запрос — котировки Мосбиржи (iss.moex.com) по нажатию кнопки.
